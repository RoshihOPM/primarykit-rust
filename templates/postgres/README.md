# {{project_name}}

Independent Axum + PostgreSQL service generated by PrimaryKit Rust.

## Development

Start PostgreSQL 16 and configure DATABASE_URL. You can use the included
compose.yaml for local development:

    docker compose up --build

    curl http://localhost:8000/health/live
    curl http://localhost:8000/health/ready

Or launch the API locally against a running PostgreSQL:

    export DATABASE_URL=postgres://primarykit:primarykit_dev_only@localhost:5432/primarykit
    cargo run

The service applies versioned migrations before it accepts traffic.
Readiness returns HTTP 503 if PostgreSQL is unavailable. Liveness does not
touch PostgreSQL. SQLx uses a connection pool (default max 5 connections).

## Tests

    cargo fmt --all -- --check
    cargo clippy --all-targets -- -D warnings
    cargo test

With DATABASE_URL set, tests also run migrations against PostgreSQL and verify
readiness. Do not point tests at a production database.

## Security note

The included database user/password is for local development only.
There is no authorization, permissions layer, or business API yet. Add
those components before exposing an application to the public internet.
