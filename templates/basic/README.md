# {{project_name}}

Independent Rust/Axum HTTP service generated by PrimaryKit Rust.

## Development

    cargo run

Default binding: 0.0.0.0:8000 (override with BIND_ADDR).

Endpoints:

- GET /health/live — process liveness
- GET /health/ready — readiness (currently no external dependencies)

## Quality checks

    cargo fmt --all -- --check
    cargo clippy --all-targets -- -D warnings
    cargo test

## Docker

    docker build -t {{project_name}} .
    docker run --rm -p 8000:8000 {{project_name}}

This starter deliberately does not claim to include a database, authorization,
queues, or persistence. Add these as independently tested modules.
